# ruggie-lib
The high-level Nintendo 3DS API to develop games in Rust.

It is built upon [citro2d_sys](https://git.sr.ht/~sheepy/citro2d-rs), [citro3d_sys](https://github.com/rust3ds/citro3d-rs) and [ctru-rs](https://github.com/rust3ds/ctru-rs). The [cargo3ds](https://crates.io/crates/cargo-3ds) toolchain is used to generate the compiled 3dsx.

## WARNING: WIP
This library is still work in progress. The way to work with it may vary and most of what needs to be done to have a fully functioning product is not quite there yet.
